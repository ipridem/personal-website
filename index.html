                        D-02 // PURPOSE-CONDITIONED-DISCLOSURE-CONTROL
                        HONOURS CAPSTONE · ACTIVE
                    

                    

                        
                            purpose-conditioned-disclosure-control ↗
                        
                    

                    

                        Purpose-bound REST API response filter addressing OWASP API3:2023 and Zimbabwe’s Cyber
                        and Data Protection Act (CDPA s.7 & s.9). Intercepts responses from Apache Fineract via a
                        Flask after_request hook, maps 61 JSON key patterns to 16 canonical identifiers,
                        and redacts out-of-purpose or unknown fields ([REDACTED]) with SHA-256 JSONL audit
                        logging.
                    

                    
    
                        
  • Evaluated on 80 frozen Apache Fineract responses (3,500 scored fields)
    • 
                        
  • UK Open Banking v4.0 ground truth + Cohen’s kappa blind labelling
    • 
                        
  • Benchmarked vs type-based & key allow-list baselines (12,000 timed calls)
    • 
                    

                    

                        

                            Python 3.12 / Flask
                            Apache Fineract
                            OWASP API3 / CDPA
